Java Collections Challenge

Project Description

This project demonstrates the use of Java Collection Framework to store, manage, and process data using ArrayList, HashMap, and Queue.

Features

1. ArrayList Challenge

- Add elements
- Remove elements
- Update elements
- Search for an element
- Display all elements

2. HashMap Challenge

- Add key-value pairs
- Retrieve values using keys
- Update existing values
- Check whether a key exists
- Display all records

3. Queue Challenge

- Add elements to the queue
- Remove elements from the queue
- View the front element using peek()
- Display all queue elements

Technologies Used

- Java
- VS Code
- Java Collection Framework

How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Compile the Java files.
4. Run the required Java class.
5. View the output in the terminal.
