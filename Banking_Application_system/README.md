Banking Application

Project Description

A simple Java-based Banking Application to manage basic banking operations.

Features

- Deposit money
- Withdraw money
- Check account balance
- Exit the application
- Handle invalid inputs

Technologies Used

- Java
- VS Code

How to Run

1. Open "BankingApp.java" in VS Code.
2. Compile using "javac BankingApp.java".
3. Run using "java BankingApp".
